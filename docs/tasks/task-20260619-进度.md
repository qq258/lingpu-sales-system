## 本次实施详情（2026-08-09）

### 第 7 条：品牌型号树 + 库存合并页

**功能**：
- 左侧 `el-tree` 两级结构：品牌 → 型号；型号节点 label 显示当前门店总库存数量（如「iPhone 15 Pro Max 5 台」）。
- 树节点支持品牌/型号的**新增、编辑、删除**（品牌删除受"存在型号不可删"约束，型号删除为软删除停用）。
- 右侧上半为筛选区：支持按**颜色、内存**筛选，并保留 IMEI/IMEI2/SN 关键字搜索。
- 右侧下半为库存 square 网格：**只显示在库商品**，含品牌/型号/规格/IMEI/门店/在库标识。
- 左右联动：**仅点击型号节点**才改变右侧显示内容；点击品牌节点仅展开/高亮。

**服务端**：
- 新增 `GET /api/v1/inventory/tree`：返回品牌→型号两级数据，并聚合当前门店（或全部）`wh_inventory.quantity` 作为型号总库存。

**前端**：
- 新增页面 `portal/src/views/InventoryManage.vue`，路由 `/inventory`（导航标签由「查库存」改为「库存」）。

### 第 12 条：删除库存（必填删除原因 + 操作记录）

**服务端**（均要求 `delete_reason` 非空，事务内执行）：
- `DELETE /api/v1/inventory/imei/:id`：删除单条在库 IMEI。
- `DELETE /api/v1/inventory/model/:modelId`：清空某型号全部在库库存。

**删除逻辑（事务）**：
1. `wh_inventory_imei` 软删除（`status = 'deleted'`），保留历史可追溯；
2. 扣减 `wh_inventory` 汇总数量（单条 -1 / 按型号清零）；
3. 写入 `wh_inventory_log` 流水（`change_type = 'inventory_delete'`，备注含删除原因）；
4. 写入 `sys_operation_log` 操作日志（`module = 'inventory'`、`action = 'delete'`、detail 含原因与数量）。

**前端**：
- 库存 square 悬停出现删除按钮 → 弹窗**必填删除原因** → 确认删除后刷新右侧与树。
- 选中型号时提供「清空该型号库存」批量删除入口（同样必填原因）。

**构建验证**：`portal vite build` ✅ ｜ `server tsc` ✅
